# Extensions

Projects built on VABAM.

| Project | Description |
|---|---|
| [VABAM-Circadian](https://github.com/JunetaeKim/VABAM-Circadian) | VABAM applied to circadian *Bmal1*/*Per2*-luciferase recordings of cancer cell lines (10-min sampling). θ controls circadian amplitude while z keeps the waveform; includes analyses of clock-gene knockouts, circadian phenotypes and drug response. |
